Tentang Saya

Saya mahasiswa S1 Sistem Informasi di Universitas Teknologi Digital Indonesia (UTDI), Yogyakarta. Saya terbiasa mengembangkan aplikasi web dengan PHP, Laravel, dan MySQL.

Selain menulis kode, saya juga menikmati tahap perancangannya: menyusun basis data lewat ERD dan memetakan alur sistem dengan UML sebelum mulai mengimplementasikan fitur.

Beberapa proyek saya kerjakan bersama tim, jadi saya sudah terbiasa membagi tugas, memakai Git untuk kolaborasi, dan menyelesaikan pekerjaan sesuai tenggat. Saya terus belajar dan senang mencoba teknologi baru lewat praktik langsung.
